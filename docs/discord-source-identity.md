# Discord 来源频道校验

Discord 消息 ID 在频道之间不能重复。QQ 发送前读取各日归档的消息 ID 和频道 ID；同一 ID 出现在多个频道、原始记录缺失或频道不匹配时，返回 `blocked_source`，隔离该条，不调用 QQ 发送接口。归档暂不可读时保留待发状态，下一轮重试。

手动补发预览将冲突消息标记为不可发送，提交补发时重新检查；已排队的自动转发和历史补发也执行发送前检查。冲突会同时阻止该 ID 的所有频道版本，保留原始归档与已有发送记录供核查，不按作者名猜测来源或更改群路由。

扩展 0.2.63 检查消息 DOM 中的频道 ID，并在异步读取配置后重新检查页面路由，防止频道切换期间把旧 DOM 标记为新频道。服务端拒绝 DOM 频道与提交频道不符的消息。更新文件后需在 Edge 扩展管理页重新加载扩展，并刷新采集标签页。
