# 内容观察台

只读接入版已部署，支持 DC / TG 归档原文、图片、QQ 队列与分段回执。仓库内静态演示仍可独立打开，但与真实入口完全分开。

本地启动真实查看（Node.js + OpenSSH；远端 Python 3.10+，不需第三方包）：

```powershell
node scripts/open_collector_viewer.cjs <SSH目标> <已保存的主机别名> <远端项目绝对路径>
```

连接信息仅在命令参数或忽略的本地启动文件保存，不写进仓库。保持已有 SSH key、主机别名和严格主机校验。启动后打开 `http://127.0.0.1:18770`，Ctrl+C 停止本地入口和隧道。查看服务在同一 SSH 会话前台运行，退出后立即结束或最多空闲 120 秒退出，不安装常驻计划任务。仅关闭网页会停止内容轮询；若要彻底关闭连接，应关闭启动终端。前端和只读服务位于远端项目的 `viewer/`、`scripts/collector_viewer.py`，业务进程无需重启。

浏览器每 5 秒读取一次快照；后台标签页暂停轮询。查看服务缓存 4 秒，只读打开业务 SQLite，忙等待 50 毫秒，每库 SQL 执行预算 200 毫秒，不更改业务库或数据库索引。图片按需读取允许附件目录里的已登记图片。健康接口在服务端使用原令牌，浏览器只经本地代理访问独立查看凭据保护的接口，凭据不写进 URL、浏览器或 Git。

当前范围：DC 今昨两个归档日合并后最近 100 条版本；TG 最近 100 条版本；QQ 最近 100 条常规任务加最多 100 条待发任务、最近 300 条分段记录和 20 条补发请求。搜索和筛选仅作用于此窗口，尚无全历史分页。归档计数是窗口计数；队列状态总数是整个 outbox 的计数。跨日去重限查询窗口，显示的入库时间不是全历史最早时间保证。

旧版没有实际发送正文、不可变首次入队、完整重试、请求开始和心跳日志结构字段：均明确标注缺失；QQ 显示来源 / 队列正文快照与实际分段回执。补发请求与近期分段可查看，但尚未完整关联所有 replay_items；仅有分段时不宣称整条发送完成。新记录提交后的观察延迟主要为 5 秒轮询、缓存与查询耗时，不是源平台发布到采集或 QQ 送达时间。查看服务仍消耗少量 CPU、磁盘和网络，未承诺零影响。

隔离验证：`python -m unittest discover -s test -p test_collector_viewer.py -v`。测试只使用临时数据库和构造图片，不调用发送接口。

以下是纯演示模式：

本目录是可独立运行的界面原型，数据和图片均为本地构造，未接入远程归档、SSH 或 QQ Bot。界面持续显示演示标记；连接状态也为演示。

从项目根目录启动：

```powershell
node scripts/preview_collector_viewer.cjs
```

在浏览器打开 `http://127.0.0.1:18770`；Ctrl+C 关闭。端口冲突时用环境变量 `MUSE_VIEWER_PREVIEW_PORT` 指定其他端口。也可直接打开 `viewer/index.html`，复制功能可能受浏览器本地文件权限限制。

可用交互：五个导航视图、正文/频道/ID 搜索、状态筛选、QQ 目标群筛选、消息详情抽屉、原图放大、处理时间线、QQ 分段、复制正文以及模拟新增消息。支持窄屏、键盘关闭、抽屉焦点约束及详情标签方向键切换。

静态预览只允许访问固定的前端资源，监听本地回环地址；不公开项目目录、业务数据或凭据。关闭预览不影响现有业务进程。

真实入口由查看服务把 `demo-data.js` 替换成 `live-data.js`，不返回演示数据文件。实际发送正文、首次入队和完整重试事件仍需要业务方补记，完整规划见 `docs/collector-viewer-plan.md`。
